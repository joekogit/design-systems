The framework

Typed agents, visible execution

Everything an agent does is a typed call you can trace, replay and test.

Typed end to end

Tools declare Zod schemas; the agent's inputs and outputs are typed and validated at the boundary.

Visual console

Every step, tool call and token streamed into a local console. No print-statement debugging.

Workflows

Compose agents into supervised workflows with retries, branching and human approval steps.

Any provider

OpenAI, Anthropic, Google or a local endpoint, swapped with one line.

Replay

Every run is recorded and replayable against a different model, so you can compare without re-running side effects.

Testable

Agents are ordinary functions. Mock a tool and assert on the result in your existing test runner.

Observability

See what the agent actually did

The console shows the reasoning, every tool call with its arguments and result, token counts and latency per step. When an agent goes wrong you can see the exact step where it did.

  • Per-step reasoning, arguments and results
  • Token and latency accounting per call
  • Runs recorded and replayable

Questions

Is the framework really free?

MIT licensed, including commercial use, with no feature gating. The paid tiers add hosted trace storage and team features, not framework capability.

Does it lock me into a provider?

No. Providers are adapters; switching between OpenAI, Anthropic, Google or a local endpoint is a one-line change and the rest of the agent is untouched.

How do I test an agent?

Agents are plain functions. Mock the tools, call the agent, assert on the output — no special harness and no network required.

Where do traces go?

Locally by default, to disk, with nothing transmitted. The hosted console is opt-in and exports standard OpenTelemetry spans.

Applying this system

  • One electric-green accent carries every CTA, status pill and the logo mark. There is no second accent anywhere.
  • The dark canvas is the only page surface — no light-mode rhythm, no alternating bands.
  • Hairline-bordered cards are the primary chrome: no shadows, no fills, just precise 1px rectangles.
  • A dashed rule between sections is the brand's only ornamental line. Use it sparingly as a rhythm cue.
  • Buttons are tight 6px rounded rectangles, never pills. Full pills are reserved for inline status tags.
