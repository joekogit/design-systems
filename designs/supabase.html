The platform

Everything attached to your database

Each piece works on its own. Together they are a backend you did not have to assemble.

Postgres database

A dedicated Postgres instance with extensions enabled, point-in-time recovery and no proprietary query layer in front of it.

Authentication

Email, magic links, phone and twenty OAuth providers, enforced at the row through Postgres policies.

Storage

S3-compatible object storage with image transformation on the fly and the same policy engine as the database.

Realtime

Subscribe to inserts, updates and deletes over websockets, filtered by the same row-level rules.

Edge functions

Deno functions deployed to the edge, close to your users and next to your data.

Vector search

pgvector built in, so embeddings live beside the rows they describe instead of in a second database.

Row level security

Authorisation in the database, not the API

Policies are written in SQL and enforced by Postgres itself. A misconfigured client cannot read what a policy forbids, because the check happens below the API rather than inside it.

  • Policies expressed as ordinary SQL
  • Enforced for REST, realtime and storage alike
  • Testable with a plain SQL test suite

No lock-in

It is just Postgres underneath

Take a pg_dump and leave whenever you like. The platform adds extensions and services around a standard database rather than replacing it with something you cannot export.

  • Standard pg_dump and pg_restore
  • Direct connection string available
  • Core platform under Apache 2.0

Common questions

Is it really just Postgres?

Yes. You get a connection string to a standard Postgres instance. Everything the platform adds is built with extensions and services around it, so pg_dump gets you out cleanly.

What happens if a project is idle?

Free-tier projects pause after a week without activity and can be restored from the dashboard in about a minute. Paid projects never pause.

Can we self-host?

The core platform is Apache 2.0 licensed and there is a documented Docker Compose setup. Some managed conveniences — the dashboard's log explorer in particular — are cloud-only.

How do backups work?

Daily backups on Pro with seven-day retention, and point-in-time recovery to any second within the retention window as an add-on.

Applying this system

  • The emerald is the only chromatic event on the page. Everything else is a greyscale ladder from hairline to ink.
  • Composited product UI screenshots — dashboard, SQL editor, log stream — are the only decorative element. No photography, no illustration.
  • Button radii stay tight at 6–8px. Nothing in this system is a pill.
  • Code blocks sit on a near-black surface with monospace inline code; the developer DNA should be visible on every marketing surface.
  • The featured pricing tier inverts to near-black rather than turning green — the green stays reserved for buttons and dot accents.
