Common questions

Can we self-host?

The editing environment is a React application that runs anywhere you like. The content backend is a hosted service; a self-hosted backend is available on Enterprise agreements only.

How is usage measured?

By API requests and stored documents. Queries served from the CDN cache do not count, which for most production sites is the large majority of traffic.

What happens to our content if we leave?

Export the full dataset as newline-delimited JSON plus the original assets, at any time, from the CLI. There is no proprietary format to unpick.

Does it work with our framework?

There are typed clients for JavaScript, Python, PHP, Go and Swift, plus a plain HTTP API. Nothing about the platform assumes a particular front end.

Applying this system

  • The near-black canvas is the identity, not a dark mode. There is no light counterpart to design.
  • Display type runs to 112px with roughly -4% tracking. That compression is the brand voice — do not loosen it to be safe.
  • The grey ramp is strictly achromatic. Introducing a warm or cool grey undoes the discipline the whole system rests on.
  • Coral is the CTA; electric blue is the hover state for every interactive element. They are two roles, not two accents.
  • IBM Plex Mono carries code and technical labels, giving the editorial display type a developer counter-register.
