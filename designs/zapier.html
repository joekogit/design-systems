HOW IT WORKS

A trigger, then some steps

Every automation is the same shape, which is why non-developers can build them and still trust them.

Triggers

Something happens in one app — a form is submitted, a deal moves, a file lands.

Actions

Then things happen in others, in order, with the data mapped between them.

Paths and filters

Branch on a condition so one automation handles several cases without duplicating it.

Schedules and delays

Run on a timer, or wait a day before the follow-up so it does not arrive at midnight.

Errors you can see

Failed runs held with the data attached, replayable once you have fixed the cause.

Shared with the team

Automations owned by a team rather than by whoever happened to build them.

RELIABILITY

Failures are held, not dropped

When a step fails the run is held with its data intact rather than discarded. Fix the cause, replay it, and nothing is lost — which is the difference between an automation you trust and one you check every morning.

  • Failed runs held with data intact
  • Replay after fixing the cause
  • Alerts on repeated failure

QUESTIONS

What counts as a task?

Each successful action a step performs. Triggers and filtered-out runs are not counted, so a heavily filtered automation is cheap to run.

Do you charge per user?

No. Team plans include unlimited users; you pay for tasks. That is deliberate — automation gets more valuable the more people can build it.

What if an app I need is not supported?

There are webhook and HTTP steps for anything with an API, and a developer platform for publishing a proper integration.

What happens when a step fails?

The run is held with its data rather than discarded. Fix the cause and replay it; nothing is lost in the meantime.

Applying this system

  • The canvas is warm cream, not pure white. The temperature is the brand voice.
  • Ink is a deep coffee rather than black, and that warmth carries through every neutral in the ladder.
  • One saturated orange is the conversion signature and appears nowhere decorative.
  • 12px is the middle-radius signature for both buttons and cards — neither sharp nor pill.
  • Every neutral in the greyscale carries warmth; introducing a cool grey anywhere breaks the temperature.
