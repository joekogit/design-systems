THE PLATFORM

One database, several workloads

Documents, full-text search, vector similarity and analytics — on the same data, without a pipeline between them.

Document model

Store the shape your application actually uses. Adding a field is not a schema migration and a maintenance window.

Search built in

Full-text search on the same records, so there is no index to keep in sync with a second system.

Vector search

Embeddings stored beside the documents they describe, queried in the same statement.

Analytics nodes

Run heavy aggregations on separate nodes without touching operational latency.

100+ regions

Deploy across three clouds, with data pinned to a region for residency requirements.

Encrypted in use

Queryable encryption keeps sensitive fields encrypted even while being searched.

FLEXIBILITY

Schema changes that are not events

A document database lets the shape of a record evolve with the application. Adding an optional field is a code change rather than a coordinated migration, a maintenance window and a rollback plan.

  • Add fields without a migration
  • Schema validation when you want it enforced
  • Versioned documents handled in application code

QUESTIONS

Is the free tier really free?

Yes, permanently, with 512MB of storage on a shared cluster. It is not a trial and it does not expire — plenty of small production apps live on it.

Do I lose transactions with a document model?

No. Multi-document ACID transactions are supported across collections and shards, with the same guarantees you would expect.

Can I enforce a schema?

Yes, when you want it. Schema validation rules are opt-in per collection, so early development stays flexible and production stays strict.

Which clouds can I deploy to?

AWS, Azure and Google Cloud, across more than a hundred regions, including multi-cloud clusters spanning providers.

Applying this system

  • Deep teal hero bands with bright green pill CTAs are the opening signature; the documentation surfaces below are stark white.
  • Buttons are full pills and cards sit at 12px — the contrast between the two radii is deliberate.
  • Course and resource tiles carry colour category tags in purple, orange, green and teal.
  • One sans family carries every UI surface, with a mono face only inside code mockups.
  • The featured pricing tier takes a mint highlight rather than the deep brand green, keeping the CTA green distinct.
