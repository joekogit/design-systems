THE PROBLEM

Auth is the hard part, not the calling

Every integration is an OAuth dance, a token refresh and a rate limit. That is the work Conduit does.

Managed OAuth

We hold the flow, the refresh and the revocation for every connected account, per end user.

Typed schemas

Every tool exposes a JSON schema the model can be constrained to, so calls are valid before they are sent.

Rate limits handled

Backoff, retry and per-provider quotas managed for you rather than rediscovered in production.

Per-user connections

Each of your users connects their own accounts; tokens never mingle.

Scoped and revocable

Least-privilege scopes by default, revocable per connection from a dashboard.

Framework agnostic

Works with any agent framework, or with plain function calling and no framework at all.

QUESTIONS

Do you store my users' tokens?

Yes, encrypted at rest and scoped per connection, so your agent can act on a user's behalf without you building token storage. Self-hosting is available on Enterprise if that is unacceptable.

What happens when a provider changes its API?

We update the schema and version the change. Breaking changes are versioned rather than shipped silently, so your agent does not start failing overnight.

Does it lock me into a framework?

No. It is an HTTP API with typed schemas. Use it with an agent framework, or with plain function calling and no framework at all.

Can I add a tool that is not listed?

Yes — define it with a schema and an auth config and it behaves like a built-in, including the managed OAuth flow.

Applying this system

  • A single deep-blue accent carries the CTAs, the wordmark and the spotlight glow. There is no second accent.
  • One sans family carries everything except code, which is monospace. No display face.
  • The dark canvas runs top to bottom; depth comes from brightness steps between card surfaces, not shadow.
  • The hero is a 2×2 grid of code and output panes — the brand signature, and it should stay a terminal rather than becoming an illustration.
  • CTAs sit at a compact 8px rather than full pills — the developer-tool dialect again.
