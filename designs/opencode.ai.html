[ features ]

built for people who already live in a terminal

no gui, no account, no cloud state. it reads the repo on disk and edits files in place.

tui first

a full-screen terminal interface with panes, scrollback and vim keybindings. runs fine over ssh.

diffs before writes

every edit is shown as a diff and applied only when you accept it. nothing is written silently.

any model

openai, anthropic, google, or a local endpoint. bring your own key and it never touches ours.

repo aware

builds a local index of the tree, so a question about one file knows about its callers.

runs your tests

executes the command you configure, reads the failure, and iterates until it passes or you stop it.

no telemetry

zero network calls except to the model provider you configured. verify it with tcpdump.

[ workflow ]

every command shown before it runs

the agent proposes a command, you see it, you approve or reject. no hidden shell execution, and a full transcript of what ran is written to the session log.

[ faq ]

does it need an account?

no. the oss build reads a provider key from your environment and never contacts us. an account exists only for the optional managed proxy.

will it work over ssh?

yes, that is the point. it is a terminal program with no gui dependency, so it runs on a headless box the same as on a laptop.

can it use a local model?

yes. point it at any openai-compatible endpoint, including a local runtime, and it works identically.

what gets written to disk?

a session transcript and a local index under the project directory, both gitignored by default. nothing else.

Applying this system

  • Every text role is monospace. There is no sans-serif anywhere in the chrome, and introducing one breaks the entire identity.
  • One warm cream body background across the whole page — no surface alternation between sections.
  • A single dark surface exists, reserved exclusively for the hero TUI mockup.
  • ASCII bracket markers ([+], [-], [x]) serve as bullet glyphs in feature lists and FAQ rows.
  • Interactive elements take a 4px radius; sections themselves are sharp rectangles separated by 1px hairlines with no decorative dividers.
