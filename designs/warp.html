What changes

A terminal that keeps its shape

Everything here exists because a scrollback buffer is a bad interface for work you need to come back to.

Blocks, not scrollback

Every command and its output is one addressable block you can collapse, copy, re-run, bookmark or share as a link.

A real editor

Selection, multiple cursors, undo and find — on the command line, behaving the way they do everywhere else.

History that is searchable

Fuzzy search across every command you have run, scoped by directory, with the working directory and exit code attached.

Shared sessions

Send a colleague a link to a live session or a single block. They see the command, the output and the environment it ran in.

Written in Rust

GPU-accelerated rendering, under 40ms from keystroke to frame, on a hundred thousand lines of output.

Workflows

Save a parameterised command with a description, then find it by what it does rather than by remembering its flags.

Blocks

Every command is an object

Output stops being an undifferentiated stream. A block knows which command produced it, in which directory, with which exit code — so you can fold it, re-run it, or send someone a permalink to the failure.

Questions

Does it work with my shell?

Yes — zsh, bash and fish, with your existing configuration, aliases and prompt left alone. Relay adds a layer above the shell rather than replacing it.

Does my command history leave my machine?

Only if you turn on cloud sync, which is off by default. With it off, history is stored locally and nothing is transmitted.

Is it available on Linux?

Yes, as of 2.0, on x86_64 and arm64 with packages for Debian, Fedora and Arch. Windows is in beta.

Will it work over SSH?

Blocks and history work on the remote host once the lightweight helper is installed there; without it you get a standard terminal session with local blocks only.

Applying this system

  • The only 'colour' in the system is an off-white that doubles as body text on the canvas and as the primary button fill. There is no chromatic brand accent.
  • The canvas is warm brown-dark, not black. That warmth is the brand — every neutral, including dividers and body text, carries a hint of it.
  • Button radii are extremely tight at 3–4px. Pills are reserved for icon containers and nothing else.
  • Inter with DM Mono is the canonical pairing; Instrument Serif appears only as an occasional editorial italic.
  • Terminal mockups are the entire decorative system. No gradients, no atmospheric overlays, no illustration.
