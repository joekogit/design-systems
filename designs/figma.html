QUESTIONS

Do viewers cost anything?

No. You pay per editor. Anyone can be invited to view and comment for free, which is what makes sharing work across a company practical.

Does it work offline?

Recently opened files are cached and editable offline, syncing when you reconnect. Opening a file you have never viewed needs a connection.

Can I export my files?

Yes, in an open format plus flat assets. Nothing is trapped, though the collaboration is obviously what you lose by leaving.

How do libraries version?

A publish creates a release with a diff. Consuming files choose when to accept it, so a token change never silently rewrites someone's work in progress.

Applying this system

  • The system core is monochrome — black and white carry every CTA, every body line and every footer link.
  • Oversized pastel colour-block sections define the narrative rhythm of a long page. They are sections, not cards.
  • The pill is the only button shape. There are no square buttons anywhere in this system.
  • The variable typeface is used at unusually fine weight increments, so the type reads as one voice flexing rather than a multi-weight family.
  • A mono face is reserved for category labels, eyebrows and captions — always uppercase with positive tracking, flagging taxonomy without competing with the display.
