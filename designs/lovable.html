Questions

Is it real code or a no-code wrapper?

Real code, in a repository you own, using ordinary frameworks. There is no proprietary runtime and nothing stops working if you leave.

Can I edit what it generates?

Yes, visually or in the code, and both edit the same underlying files. Changes you make by hand are not overwritten by later prompts.

What happens if I cancel?

Your repositories are yours and stay in your Git account. Custom domains stop resolving; the code does not go anywhere.

Does it handle the database properly?

Schema, migrations and row-level security are generated and wired up. You can review and edit all of it before anything goes live.

Applying this system

  • The parchment background is a deliberate cream — not white and not beige. It is the foundation of the warmth.
  • Every grey derives from one charcoal at a transparency level rather than being picked separately. That is what keeps the neutrals coherent.
  • Buttons carry a double inset shadow — a light top edge and a dark hairline ring — which is what gives them their tactile quality.
  • Full-pill radius is used extensively for actions and icon containers; cards step back to a softer rounding.
  • Focus states use a soft warm shadow rather than a hard ring, in keeping with the rest of the system.
