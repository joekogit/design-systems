Common questions

Are the open weights the same as the API model?

Yes, on the open line. There is no distilled 'community edition' — the artefact you download is the one the published benchmarks were run against.

What licence are they under?

Apache 2.0 on the open line, including commercial use, with no revenue threshold and no usage reporting requirement.

Where does the hosted API run?

In EU regions only, with residency guaranteed contractually rather than as a best-effort setting.

Can I fine-tune?

Yes, locally with the published weights, or through the hosted fine-tuning API which returns a private model you alone can call.

Applying this system

  • Atmospheric sunset photography carries the hero — orange through red to yellow, never a flat colour field.
  • The horizontal sunset stripe closes every page. It is the brand's signature and it belongs at the bottom, not repeated mid-page.
  • Cream-yellow surfaces carry form panels and feature cards, warming an otherwise white page.
  • A near-serif display pairs with a sans for everything else — editorial geometry rather than playful.
  • The saturated orange CTA carries every action call. Buttons stay at 8px and cards at 12px.
